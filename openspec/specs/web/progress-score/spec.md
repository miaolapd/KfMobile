# progress-score Specification

## Purpose

定义 KfMobile 移动端对 KF 进度分的展示能力：首页功能区展示当前进度分并可进入详情页，详情页呈现进度分、规则说明与扣分记录，同时明确首页功能区不再提供争夺奖励入口。

## Requirements

### Requirement: 首页进度分展示

系统 MUST 在首页功能区「KFB | 贡献」按钮下方展示进度分按钮，文案 MUST 为「进度分」并在数字部分加粗；进度分 MUST 取自远端首页当前登录用户的进度分。

#### Scenario: 正常展示进度分

- **WHEN** 已登录用户访问首页且远端返回包含进度分的页面
- **THEN** 首页在「KFB | 贡献」下方显示形如 `<b>103</b>进度分` 的按钮，数值与远端一致

#### Scenario: 进度分不可获取

- **WHEN** 远端页面缺少进度分元素或请求失败
- **THEN** 首页进度分数值显示为 `0`，且首页其余内容照常渲染

### Requirement: 进度分详情页

系统 MUST 提供本地进度分详情页，展示当前进度分（数字加粗）、进度分规则说明与扣分记录；页面 MUST 通过本地路由访问，并 MUST 复用站点统一页头与页脚。

#### Scenario: 访问进度分页面

- **WHEN** 已登录用户进入首页进度分按钮指向的地址
- **THEN** 页面显示当前进度分（数字加粗）、规则说明与扣分记录，且标题包含站点名称

#### Scenario: 无扣分记录

- **WHEN** 远端返回「当前没有任何扣分记录」等信息
- **THEN** 页面按原文展示该信息，不出现空区块或错误

#### Scenario: 未登录访问

- **WHEN** 未登录用户访问进度分详情页
- **THEN** 显示登录页面而不是进度分内容

### Requirement: 远端进度分链接本地化

系统 MUST 将远端页面中的 `kf_lv200.php` 链接转换为本地进度分页面地址，并 MUST 在详情页内将远端其它入口链接（如管理区版块）转换为本地地址。

#### Scenario: 链接转换

- **WHEN** 远端内容包含 `kf_lv200.php` 或 `thread.php?fid=4`
- **THEN** 输出页面中的链接分别指向本地进度分页面与本地版块页面

### Requirement: 首页功能区按钮集合

首页功能区 MUST NOT 再提供「争夺奖励」按钮；系统 MUST 保留导航栏与 kfolNav 中既有的争夺相关入口。

#### Scenario: 首页不再显示争夺奖励

- **WHEN** 已登录用户访问首页
- **THEN** 功能区不出现「争夺奖励」按钮，其余按钮（神秘、KFB|贡献、进度分、自助评分、咕咕镇）保持可用

#### Scenario: 导航入口保持

- **WHEN** 用户展开站点导航或 kfolNav
- **THEN** 其中的「争夺奖励」「争夺首页」入口仍可访问，行为与调整前一致
